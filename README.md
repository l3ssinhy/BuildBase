# BuildBase 🖥️

O **BuildBase** é uma aplicação web desenvolvida com o objetivo de facilitar a pesquisa e comparação de peças para computadores.

A aplicação permite que o usuário pesquise componentes de acordo com o **tipo da peça**, como processadores, placas de vídeo, memórias RAM, placas-mãe, SSDs, fontes e outros componentes.

Os dados são obtidos através do consumo de uma **API**, utilizando programação assíncrona em JavaScript. As informações retornadas são processadas e exibidas dinamicamente na página.

Para cada peça, o BuildBase apresenta informações como:

* Nome do componente;
* Tipo da peça;
* Marca;
* Lojas que oferecem o produto;
* Preço em cada loja;
* Disponibilidade do produto.

## 🎯 Objetivo

O principal objetivo do projeto é aplicar os conhecimentos adquiridos sobre **consumo de APIs**, **requisições HTTP**, **programação assíncrona** e **manipulação dinâmica do HTML com JavaScript**.

Além disso, o projeto busca oferecer uma interface simples, organizada e responsiva para facilitar a visualização e comparação dos componentes.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* API REST / JSON
* Fetch API
* Async/Await

## ⚙️ Funcionalidades

* Pesquisa de peças de computador;
* Filtro por tipo de componente;
* Exibição dinâmica dos produtos;
* Visualização dos preços em diferentes lojas;
* Indicação de disponibilidade;
* Tratamento de erros durante o consumo da API;
* Interface responsiva para diferentes tamanhos de tela.

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte da **Sprint - Consumo de API**, com foco na utilização de JavaScript assíncrono para realizar requisições a uma API e apresentar os dados obtidos de forma dinâmica ao usuário.
